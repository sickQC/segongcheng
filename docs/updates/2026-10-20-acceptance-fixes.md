# 新功能验收问题修复

## 最终行为

- 综合诊断对同一课程、学生、知识点范围、统计天数、教学定义、完整证据内容及模型/提示词配置计算输入指纹。仅统计窗口时钟向前移动时不重复推理；新增/过期证据、定义或模型配置变化时重新分析。每次请求仍保存独立记录，重复请求编号保留原有幂等规则。
- 相同输入复用此前的有效结果，并显示复用提示及来源报告编号。提交结果时按课程串行核对，两个并发推理也保留最先采纳的同输入结果；实际发生的并发模型调用仍保留调用及用量记录。失败结果不作为复用来源。
- 旧报告缺少输入指纹，不推断其运行配置，也不改写旧分数。新规则首次运行建立结果，随后同输入复用。这解决重复分析引起的分数跳变；首次估计的准确性仍需独立评测。
- 推荐预算和教师估时使用原生数字输入，保留分钟范围与页面样式；实际禁用状态和ARIA同步，手输后失焦不恢复旧值。有效范围仍由服务端校验。
- 快照标签以短编号区分，同时显示保存时间和来源诊断时间。后续升级回填明确标为“升级回填”。旧快照不重写，通过来源诊断时间与编号区分，不倒填历史时间。
- 快照接口新增`origin`、`source_report_created_at`，无需数据库迁移。旧快照兼容读取。
