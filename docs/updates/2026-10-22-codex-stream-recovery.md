## 已修复的适配器问题

- 原先等待 CLI 进程退出后才解析全部输出。改为持续读取 JSON 事件，在取得答案及 `turn.completed` 后返回，并回收此次推理进程；不等待 CLI 后续退出阶段。
- 原先遇到中途的 `error` 事件立即拒绝整次调用，即使后续重连成功。现在以终止事件为准：允许中间连接恢复；`turn.failed`、不完整流、空回复及工具调用仍被拒绝。
- 本项目单次 CLI 调用设置 `analytics.enabled=false`，减少可选分析上报的额外网络等待。未修改全局 CLI 配置、登录状态、系统代理、TLS 校验或工具限制。
- 保留连接超时、TLS 中断、模型目录不可达等白名单标签与重连计数。5E 调用记录保存这些信息；不保存原始 stderr、认证信息或请求内容。

配置依据：https://learn.chatgpt.com/docs/config-file/config-reference （`analytics.enabled`、模型 provider 与传输配置）。
