# 2026-10-20 学习流程更新与体验说明

## 本轮变化

课程讲义、课堂答疑、错题诊断与 5E 现在通过同一课程知识点连接。学生先选课程章节，再选本章知识点，可以阅读其对应的讲义小节；也可以从讲义或错题直接进入对应知识点的学习。

- 讲义原文支持 Markdown 表格、代码、目录和小节定位；答疑引用可打开并高亮原文。
- 从测验或小练习诊断进入 5E，会固定保存当时的原题、原答案和诊断；新的学习会话还保存配套讲义小节原文，供模型参考。
- 学习中可查讲义再继续。评价提示指向页面实际小测；完成后可回看原题、再做知识点小练习或查看报告。
- 报告列出近期 5E 会话。点击“分析最近学习记录”生成新报告时，会纳入对应知识点的新作答；已有报告保留原证据快照，正式测验原分数保持不变。
- 教师端显示课程管理、课程讲义、测验管理与教师看板，学生端显示学习和作答入口。

## 快速体验

1. 学生打开“课程目录”，从一个知识点进入 5E，核对章节与知识点是否自动选中。
2. 在 5E 下点击“阅读对应小节”，核对讲义标题、定位小节和高亮；从讲义上方的对应知识点入口返回 5E。
3. 打开已提交的测验错题或小练习诊断，点击“针对这道题学习（5E）”，核对原题、原答案和诊断，再提交自己的思考。
4. 完成评价小测及解释后，检查回看原题、小练习和学习报告入口。进入报告后点击“分析最近学习记录”，可展开证据核对新作答。
5. 教师登录后检查课程、讲义、测验管理与看板；学生专用学习和作答入口不显示。

自动测试不需要模型密钥。真实 AI 诊断、答疑和阶段反馈需要按 README 接好自己的模型；只阅读讲义、浏览课程和服务端判分可以独立体验。

## 课程与讲义的对应

种子课程仍为两章四个知识点，讲义共有六份。教学目录由教师维护，讲义作为配套资料按小节与知识点绑定。

| 课程知识点 | 配套讲义与小节 |
| --- | --- |
| 功能需求与非功能需求 `KP-REQ-01` | 《软件需求工程》→ 功能性需求与非功能性需求 |
| 用例与参与者 `KP-REQ-02` | 《软件需求工程》→ 用例与参与者 |
| 软件验证与确认 `KP-VAL-01` | 《软件测试：验证确认与测试用例设计》→ 软件验证与确认 |
| 等价类划分 `KP-TEST-01` | 同上 → 等价类划分 |
| 边界值分析 `KP-BOUND-01` | 同上 → 边界值分析；教师在课程中添加该编号后可使用 |

没有配置 5E 的讲义仍可阅读和答疑，页面明确提示。教师自行上传讲义、阅读行为采集、完整画像和个性化路径推荐仍是后续工作。

## 接口变化

路径前缀为 `/api/v1`，继续使用登录会话、课程权限和写请求的 Origin/CSRF 校验。

| 接口 | 本轮新增内容 |
| --- | --- |
| `GET /courses/{course_id}/resources` | Markdown 格式标识与对应的课程知识点编号 |
| `GET /courses/{course_id}/resources/{resource_id}/content` | 返回 `resource_id`、`title`、`markdown`，只读取允许访问的课程讲义 |
| 课程答疑响应的 `citations[]` | 增加 `section`，用于定位原文小节 |
| `GET /courses/{course_id}/learning-templates` | 增加 `chapter_id`、`chapter_title`、`chapter_order`、`lectures[]`，按课程目录顺序返回 |
| `POST /learning-sessions` | 可选 `source_event_id`；服务端核对作答归属、课程、知识点和诊断完成状态 |
| `GET /learning-sessions/{session_id}` | 增加 `chapter`、`lectures`、`source`、`practice_available` |
| `GET /courses/{course_id}/learning-sessions` | 增加知识点编号、来源与更新时间，按最近更新排序，时间明确携带 UTC 时区 |
| `GET /courses/{course_id}/attempts/{attempt_id}/diagnoses` | 增加 `knowledge_point_id` 和 `five_e_available`，用于提供正确学习入口 |

`source_event_id` 指向本人的真实测验或小练习作答。来源未知或不属于本人返回 404；知识点不匹配返回 422；诊断尚未完成返回 409。同一请求编号不能改绑另一条作答。

机器可读接口见 [OpenAPI](../api.yaml)。提示词版本为 `learning-5e-v4`，讲义、原题和旧诊断作为数据输入，新回答仍是阶段评估依据。
