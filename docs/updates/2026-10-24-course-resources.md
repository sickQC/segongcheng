# 课程资料上传与答疑

2026-10-24：资料不再只从固定演示课程的仓库目录读取。教师可以向本人有编辑权限的课程上传资料，课程成员可以阅读、下载并提问；检索仅使用本课程未删除、解析成功的当前版本。

## 已有六份讲义

仓库中的概述、需求、体系结构、设计、构造、测试六份 Markdown 讲义已可作为正式资源导入。它们保存原文件、解析正文、分块和关联信息，支持与上传文件相同的编辑、版本管理、删除及检索。来源标为“系统导入”，不伪造教师上传时间或上传者；教师实际上传的文件标为“教师上传”。

默认课程的需求讲义绑定已有两个需求知识点，测试讲义绑定三个测试知识点；其余四份暂为课程通用资料，因为目录中还没有对应知识点。教师新增知识点后可以编辑资料关联，不会自动往课程灌入 RAG 元数据中的全部知识点。

初始化脚本自动导入六份，重复运行保留标题、关联、版本及删除状态。仓库文件是导入来源，正式资源是数据库快照；修改源文件不会覆盖教师维护的版本。更新时请教师上传新文件。

## 使用与升级

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-lock.txt
.\.venv\Scripts\python.exe -m alembic -c backend/alembic.ini upgrade head
.\.venv\Scripts\python.exe scripts/import_course_documents.py
npm.cmd ci --prefix frontend
npm.cmd run build --prefix frontend
```

然后重启后端。默认导入预置课程；需要向另一门已有课程导入时可传 `--course-id`，也可由该课程教师在页面点击“导入六份示例讲义”。新课程可以直接上传自己的资料，不必导入示例。

教师进入课程的“课程讲义”，在“资料管理”点击“上传资料”，填写标题、可选说明、章节及知识点，选择文件后提交。解析状态会自动刷新，失败原因保留，可以重新解析或上传修正后的新版本。原文件和文件历史保留；教师可以将解析成功的历史版本重新设为当前版本。

学生在“资源学习”中选择资料预览、下载和提问，也可以从知识点的“阅读配套资料”进入。删除资源后学生不能再访问，答疑也不再检索；数据库保留原文件与历史，不提供删除后的恢复入口。

## 视频上传与点击完成

教师同样点击“上传资料”，选择 MP4 或 WebM（每份最多 200 MiB）后点击“上传视频”。上传成功即为“可学习”，无需等待文本解析；可以关联章节和知识点、编辑标题、更新文件、查看和切换历史版本、删除。文档和视频不能互相替换版本，请分别新建资源。

学生在“资源学习”的全部资料中看到视频，点击“观看视频”或从资源选择器打开视频即标记完成，刷新页面保留状态。只保存学生与视频版本的完成标记，没有完成时间、播放次数、观看时长、进度、续播位置或播放事件。每名学生状态独立；换成新版本需要重新点击，切回历史版本沿用该版本原有标记。该标记不作为有效学习时长或掌握度证据。

播放器使用浏览器原生控件，支持带权限校验的 Range 分段读取。推荐 MP4 H.264/AAC 或 WebM VP8/VP9/Opus 等浏览器可解码的组合；仅容器扩展名正确不能保证编码兼容，播放失败时会提示换用兼容文件。本轮不做视频转码、语音识别、字幕提取或视频内容答疑，配套讲义仍可正常检索。

视频文件私有保存在 `data/uploads/videos/`，可用 `VIDEO_UPLOAD_DIR` 配置绝对路径；数据库保存资源关联、文件校验摘要、相对路径和完成标记。备份或迁移时同时保存数据库与上传目录。Compose 的 `app_uploads` 卷已覆盖该目录，原生启动需保证运行账号可写。删除资源后保留原文件及历史版本，学生不能继续访问。

## 格式和解析边界

| 格式 | 预览与定位 |
| --- | --- |
| PDF | 原 PDF 在线预览及提取文字，检索分块保存真实页码，引用可跳到该页 |
| DOCX | 段落文字预览和原文件下载，按段落定位，不伪造 Word 页码 |
| PPTX | 幻灯片文字预览和原文件下载，按幻灯片定位 |
| Markdown | 标题、表格、代码与小节目录，保留小节引用 |
| TXT | UTF-8 文字预览和原文件下载 |

每份文档最大 20 MiB；视频上限另见上节。白名单与文件内容签名均校验，拒绝空文件、可执行文件和类型伪装。旧版 DOC/PPT 需要先另存为 DOCX/PPTX 或 PDF；本轮未接入 Office 原排版转换。PDF 最多 300 页，提取文字最多 50 万字符，Office 解压大小限制 50 MiB。加密 PDF、损坏文档和无法提取文字的扫描件会显示失败原因；本轮不做 OCR。

文档作为数据进入已有 RAG 护栏，保留提示注入清洗和引用校验。系统不运行上传的脚本、宏或文件内指令。

## 数据与接口

迁移 `0012` 新增 `course_resources`、`resource_versions` 和 `resource_chunks`；`0013` 新增视频文件路径及 `video_completions` 完成标记表。文档原文件以二进制保存于业务数据库，视频保存于私有文件目录，历史版本不覆盖；课程索引按当前数据库文档在内存中生成，不回退到其他课程或共享仓库。解析任务先提交待处理版本，再执行提取；进程重启中断的任务标记失败，教师可以重试。

| 接口（前缀 `/api/v1/courses/{course_id}`） | 用途 |
| --- | --- |
| `GET /resources` | 课程资源列表和解析状态 |
| `POST /resources` | multipart 上传；文档进入解析，视频直接 ready |
| `POST /resources/import-builtin` | 课程教师导入六份示例讲义 |
| `PATCH /resources/{id}` | 编辑标题、说明、章节和知识点关联 |
| `DELETE /resources/{id}` | 删除资源并从检索中排除 |
| `GET /resources/{id}/content` | 读取当前解析正文 |
| `GET /resources/{id}/file` | 下载原文件；`inline=true` 可预览 PDF 或播放视频，视频支持 Range |
| `POST /resources/{id}/complete` | 学生幂等标记当前视频版本已完成 |
| `GET /resources/{id}/versions` | 教师查询版本历史 |
| `POST /resources/{id}/versions` | 上传新版本 |
| `POST /resources/{id}/versions/{n}/activate` | 教师切换当前版本 |
| `POST /resources/{id}/retry` | 教师重试失败解析 |
| `POST /chat` | 依据本课程资料答疑，默认真实模式 |

资源、原文件、版本、编辑与删除均执行课程成员或课程教师校验，上传与其他写操作沿用 Origin/CSRF 校验。学生只能下载当前版本；教师可下载历史版本。当前仍保留 `kb:SE-02` 等旧讲义别名，按课程解析，兼容已有 5E 会话链接。

普通答疑不再依赖 `student01/student02` 或固定课程 ID。模拟历史只在显式选择模拟模式时使用。新的正式问答事件关联数据库中真实知识点 ID；历史问答与旧索引知识点 ID 不重写。没有可检索资料时，返回明确提示并记录本次问答，不伪造引用。

文字预览、PDF 原文件预览和文档下载记录对应访问事件；未据此推算阅读时长、完成率或有效投入。视频播放和下载不生成行为事件，仅打开时保存完成标记。关联有课程资料的知识点不能直接删除，应先在资料管理中解除关联。

解析器参考 [pypdf 官方文字提取说明](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)，上传使用 [FastAPI 官方文件上传接口](https://fastapi.tiangolo.com/tutorial/request-files/)。
