# D：真实学习事件导出

对应需求 M6-5，供学生下载自己的真实学习记录、教师下载所负责课程指定学生的记录。仅查询现有事件，不写入成绩、画像或推荐。

## 在网页中使用

1. 打开 http://127.0.0.1:8000 ，使用 `student01` 登录。密码见本机 `.env` 的 `SEED_PASSWORD`，不要发送到聊天或提交到 Git。
2. 进入课程的个人学习报告，选择真实数据，找到“导出真实学习事件”。
3. 选择时间、知识点和动作。动作可以留空；例如 `answered` 表示作答。
4. 点击“下载CSV”或“下载JSONL”，在浏览器下载列表查看文件。
5. 教师用 `teacher` 登录，在教师看板打开课程学生详情，在同名区域下载该学生记录；模拟预览没有此导出入口。

导出使用自己的筛选条件，不受事件列表当前页数限制。默认最近30天，最多90天、5,000条、10MiB。超过限制会拒绝并提示缩小范围，不返回悄悄截断的文件。没有匹配记录时，CSV只有表头，JSONL为空文件。

## 格式与权限

`GET /api/v1/courses/{course_id}/learning-events/export`，查询参数为 `format=csv|jsonl`、`start`、`end`、`knowledge_point_id`、`verb`；教师另须指定 `student_id`。时间必须带时区，未来终点被限制为当前时间。完整契约见 [OpenAPI](../api.yaml)。

七个字段为 `event_id/actor/verb/object/result/context/timestamp`，按时间及事件ID升序排列。时间统一UTC；CSV嵌套字段为JSON文本，带UTF-8 BOM便于表格软件显示中文。严格只包含 `context.synthetic` 为布尔值 `false` 的本人、本课程事件，不能把数字0或字符串当作真实标记。

学生只可导出本人记录；教师只可导出自己负责课程的学生记录。返回 `no-store`、`nosniff` 和事件数量头。前端切换学生、课程或条件后，不会触发旧请求的下载。

CSV对等号、加减号、@、控制字符及相应全角字符开头的单元格加文本前缀，降低表格公式执行风险。这会改变危险单元格的文本表示；程序分析应使用保留原始结构的JSONL。表格软件重新编辑或保存文件可能改变防护，不能把CSV当作可执行内容的安全容器。参考 [OWASP CSV Injection](https://owasp.org/www-community/attacks/CSV_Injection)。文件可能含学生作答原文，应妥善保管。

## 验证记录（2026-10-20）

- 新增13项自动测试：严格排除模拟事件、课程/学生隔离、空文件、中文/换行/嵌套JSON、公式前缀、两种容量限制、时间和知识点校验。
- 本机真实HTTP：学生导出9条，CSV/JSONL数量一致、教师指定学生导出ID一致；跨学生403、未登录401；业务表行数及 `.env` 摘要保持不变。登录/注销会改变会话表，未将其误作业务数据变化。
- 前端类型检查及生产构建通过，完整回归330项通过。
- 尚未替用户在真实浏览器中点击下载；布局、浏览器下载行为及大规模课程的响应时间需要单独人工验收。
