# 课堂演示顺序（约 3–5 分钟）

更新日期：2026-10-20。首次安装按 [README](../README.md)，已有克隆按 [本轮更新说明](updates/2026-10-20-learning-flow.md) 重建前端和讲义索引，再启动服务。打开终端显示的本机访问地址，提前用学生和教师账号分别登录两个浏览器窗口。

## 演示前准备

- 使用本机 `.env` 中配置的账号密码和模型；先确认课程答疑能正常返回。
- 准备一条已经完成诊断的测验错题、一条已完成的 5E 会话，减少现场等待。
- 课程答疑、AI 诊断和阶段反馈需要模型连接；讲义阅读、课程浏览和客观题判分可以单独展示。

## 学生端

1. **课程与原文**：打开课程目录，查看章节下的知识点，进入配套讲义。展示原文目录与小节跳转。
2. **课程答疑**：提问“功能需求与非功能需求有什么区别？”，展示答案引用，点击引用回到对应原文小节，说明回答依据来自内置讲义。
3. **错题到学习**：打开测验错题及诊断，点击“针对这道题学习（5E）”。核对自动选中的章节、知识点和原题、原答案，再提交一轮自己的思考。展示配套讲义入口，查阅后可继续学习。
4. **学习后的结果**：打开预先完成的 5E 会话，展示五阶段记录及评价作答。点击继续小练习或学习报告，在报告中分析最近学习记录，展开新作答证据。正式测验原分数仍保留。

## 教师端

切换教师窗口，展示课程章节和知识点管理、讲义阅读、测验管理与课程看板。看板按真实作答聚合，若选择纳入模拟记录，应说明其标记与来源。学生专用的学习和作答入口在教师端隐藏。

## 现场检查与待完成内容

- 展示一次未配置 5E 的讲义提示，说明讲义可以正常阅读和答疑，只有配置好的课程知识点可开启五阶段学习。
- 模型请求失败时查看页面错误，保留原答案后重试；演示备用记录时说明是提前产生的记录。
- 教师上传讲义、阅读行为采集、完整长期画像和个性化路径推荐仍待实现。
