# 课堂演示顺序（约 3 分钟）

准备：运行 `scripts/start.ps1`，访问 http://127.0.0.1:8000。完成首次安装与前端构建后，本次演示不需要联网。

1. **交代范围**：“这是 Sprint 0，展示一次作答从保存到诊断展示的工程流程。尚未配置模型，本次成功结果明确使用模拟数据。”
2. **模拟闭环**：选择“模拟演示”，展示预置的验证/确认概念混淆答案，提交。指出橙色提示、模拟数值、建议与追问。
3. **核查证据**：打开完整学习事件 JSON，对照 event_id 与诊断 evidence_event_ids，查看 actor/verb/object/result/context/timestamp。
4. **查看 trace**：指出 UUID、demo-fixture-v1、提示版本、处理耗时，以及没有真实 token 统计。耗时是本地模拟处理时间，不是模型延迟。
5. **展示失败保护**：返回作答，选择“真实模型调用”，填入示例后提交。显示 MISSING_API_KEY，同时原始答案保留。
6. **展示持久化**：打开诊断记录，刷新页面，两条记录仍然存在。配置真实服务后可以重试失败诊断。
