# ADR 0005：拒答判据与阈值标定

拒答（"资料中没有找到相关依据"）由两个条件共同判定，缺一不可：

1. **实词加权覆盖率** `relevance ≥ 0.39`。权重 = IDF × log(1+词长)；纯数字、单字中文、
   两字符以下英文权重为 0，避免"2024 年……"里的"2024""年"贡献虚高分数。
2. **关键实词命中** `key_hit ≥ 0.5`，即问题权重最高的两个实词至少命中一个。
   这是结构性规则，不随语料规模失效，用于挡住"实词全不命中、只有'详细''步骤'等提问脚手架命中"的伪相关问题。

提问脚手架词（哪几个/步骤/详细/常见/组成……）只在可回答性判定中被忽略，
仍保留在 BM25 与普通覆盖率中，因为它们在课程语料的小节标题里是有意义的。

阈值 `min_relevance` 只在**开发集**上标定。评测集按 ID 奇偶确定性划分为 dev / test，
`scripts/calibrate_rag.py` 只读 dev，主表在 test 上报告；选点准则是最大化两类问题的间隔，
而不是最大化 dev 上的 F1——后者等价于在开发集上过拟合。
