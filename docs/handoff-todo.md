## 建议接手顺序

1. 读 README → handoff-api.md → 需求规划；启动后先验证 P1，再手动开启四页面样例，理解字段如何显示。
2. P2：资源表/上传解析/资源管理页面 → 学习页真实资源 → 事件采集 → 图谱。先做浏览器能访问且权限正确的资源地址。
3. P3：题库管理/组卷 → attempt/交卷事务 → 判分/错题/事件 → 测验界面联调。不要在学生取卷接口泄露答案。
4. P4：检索分块/向量库 → 会话 + SSE → 答疑和引用定位，约定超时及模型失败行为。
5. P5：诊断任务 → 画像/规则推荐 → 报告接口 → 统计看板/证据下钻。
6. P6：E1/E7 的实际逻辑和所需表单/反馈组件；选做项仍需教师确认。
7. P7：填充标准数据、真实模型测试、权限及业务回归、评测与部署材料。

每个模块以“真实接口成功 + 刷新后结果仍存在 + 未授权不能访问 + 无样例模式也可演示”为交付条件。不要仅将 501 替换成静态 JSON。
